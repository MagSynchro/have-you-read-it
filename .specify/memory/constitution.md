# Constitution

1. **Test-first (NON-NEGOTIABLE).** No new or changed logic — reducers, thunks, utils, component behavior — lands without a Vitest test written before or alongside it. Pure-config or pure-markup changes are exempt.
2. **No live external data access.** *(Amended 2026-07-25, final revision — see spec 004-static-demo-data. History: originally "Server-side Reddit access only" via a Netlify Function; briefly amended to signed `client_credentials` OAuth per spec 003; both approaches hit hard walls — unauthenticated Reddit endpoints block datacenter/server IPs outright, and Reddit no longer offers self-serve OAuth app registration for an independently-hosted client, funneling registrations toward Devvit instead, which doesn't fit this project's Netlify-hosted goal.)* The app runs entirely on the bundled synthetic dataset in `src/data/demoData.js`. No network call to `reddit.com` or any Reddit-owned domain, client-side or server-side, in dev or prod. Do not reintroduce a live Reddit fetch of any kind without a new spec that documents why the datacenter-IP block and the OAuth-registration wall no longer apply.
3. **Spec before code.** Anything beyond a one-line typo or comment fix goes through spec → plan → tasks as described in §2 of `CLAUDE.md`.
4. **Deployability.** `main` must always be buildable and deployable to Netlify as a static site: `npm run build` succeeds, `netlify.toml` stays valid. (There is no longer a Netlify Function to bundle — see Principle 2's history.)
5. **Simplicity.** Don't introduce new state management, new routing, or new infra beyond what's already here (Redux Toolkit, React Router, Vite) without that being the explicit subject of a spec.
